# 🎮 2D 게임즈 컬렉션 🎮

안녕하세요! 이 프로젝트는 Unity를 사용하여 개발한 2D 미니 게임들의 모음집입니다.
Unity 게임 개발의 기본적인 개념과 로직을 학습하고 연습하기 위해 만들어졌습니다.
각 게임은 독특한 장르와 게임 플레이를 가지고 있어, 2D 게임 개발의 다양한 측면을 탐색해볼 수 있습니다.

---

## 🔧 요구 사항

*   **Unity 버전**: `2022.3.5f1`
    *   이 프로젝트는 해당 Unity 버전에서 제작 및 테스트되었습니다. 호환성 문제를 피하기 위해 동일한 버전을 사용하시는 것을 권장합니다.

---

## 🚀 시작하는 방법

1.  이 프로젝트를 컴퓨터에 클론하거나 다운로드합니다.
2.  **Unity Hub**를 실행합니다.
3.  `프로젝트` 탭에서 `열기` 버튼을 클릭합니다.
4.  다운로드한 프로젝트의 루트 폴더를 선택하여 Unity 편집기에서 엽니다.
5.  `Project` 창에서 `Assets` 폴더를 열고, 각 게임의 `Scenes` 폴더에 있는 씬(Scene) 파일을 더블클릭하여 게임을 실행하고 테스트해볼 수 있습니다.

---

## 🎲 포함된 게임들

### 🚚 Delivery Man (배달부)

**"신속하고 정확하게! 최고의 배달부가 되어보세요!"**

이 게임에서 당신은 바쁜 도시의 배달부가 됩니다. 자동차를 운전하여 고객의 패키지를 픽업하고, 장애물을 피해 목적지까지 시간 안에 배달해야 합니다.

**주요 기능:**
*   상하좌우(W,A,S,D 또는 방향키)를 이용한 차량 조작
*   부스터 아이템을 통한 속도 향상
*   충돌 시 속도 감소
*   패키지 픽업 및 배달 시스템
*   제한 시간 시스템

### 🧠 Quiz King (퀴즈왕)

**"당신의 지식을 시험해볼 시간! 퀴즈의 왕이 될 준비가 되셨나요?"**

다양한 분야의 질문에 답하며 자신의 지식을 뽐내는 퀴즈 게임입니다. 제한 시간 안에 얼마나 많은 문제를 맞힐 수 있는지 도전해보세요!

**주요 기능:**
*   `ScriptableObject`를 활용한 유연한 질문 관리
*   객관식 답변 시스템
*   문제별 타이머 및 전체 진행도 표시
*   정답/오답에 따른 즉각적인 피드백과 점수 계산
*   `EasyTransition` 에셋을 활용한 부드러운 화면 전환

### 🏂 Snow Boarder (스노우보더)

**"설원을 가르며 질주하는 짜릿함! 결승선을 향해 달려보세요!"**

눈 덮인 슬로프를 스노우보드를 타고 내려오는 속도감 넘치는 게임입니다. 점프대를 활용해 공중 묘기를 선보이고, 넘어지지 않게 균형을 잡으며 결승선에 도달해야 합니다.

**주요 기능:**
*   `Rigidbody2D`와 `SurfaceEffector2D`를 이용한 물리 기반 움직임
*   좌우 회전을 통한 세밀한 컨트롤
*   부스터를 사용한 순간적인 속도 증가
*   점프 기능
*   충돌 및 결승선 감지 로직
